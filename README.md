# Qui veut gagner des neurones ? — Application GitHub Pages

Application web mobile dérivée du PowerPoint V10 fourni, sans modifier ce PowerPoint.

## Publication sur GitHub Pages
1. Créer un dépôt public sur https://github.com/new, par exemple `quiz-avc-neurones`.
2. Décompresser ce ZIP, puis envoyer **tous les fichiers et le dossier `assets`** à la racine du dépôt (bouton **Add file → Upload files → Commit changes**).
3. Ouvrir **Settings → Pages → Build and deployment** : **Deploy from a branch**, branche `main`, dossier `/(root)` puis **Save**.
4. Attendre quelques minutes. L'adresse sera `https://IDENTIFIANT.github.io/quiz-avc-neurones/`.
5. Tester l'adresse sur téléphone. Une fois l'adresse connue, générer le QR code correspondant.

## Fonctionnement
13 questions extraites du fichier V10. Les paliers sont gagnés seulement après une bonne réponse ; une erreur ne fait pas avancer le palier. Les trois jokers sont utilisables une fois par partie et deviennent invisibles après utilisation. Le 50/50 retire intégralement deux propositions erronées. Chrono de 30 secondes ; une réponse hors délai est comptée comme fausse. Sons fournis par l'utilisateur. Le générique démarre sur l'écran final, après interaction avec la page.

## Limites
Ce jeu est une adaptation web, non une conversion des macros VBA. Les illustrations proviennent des diapositives, avec adaptation de la mise en page au mobile. La lecture automatique de sons sur mobile peut dépendre des autorisations du navigateur. Les fichiers audio et les images sont publiquement accessibles une fois le dépôt public.
